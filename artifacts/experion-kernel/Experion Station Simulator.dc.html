Shortcut keys (representative)
F1 Silence · F2 Acknowledge · F3 Alarm Summary · F4 Point Detail of selected point
In an entry field: type a value + Enter to store, Esc to cancel, ▲/▼ arrow keys to raise/lower.

Operating rules
SP changes in AUTO only · OP changes in MAN only · CAS setpoint comes from the primary.
Auto-selection: AUTO selects SP, MAN selects OP (RAISE/LOWER act on it).
Entries outside SPHILM/SPLOLM or OPHILM/OPLOLM are rejected.

Alarm response
Silence → Acknowledge → read condition → check trend → check related points → act → verify. Triage floods by priority; shelve only known nuisance alarms.

Alarm states (ISA-18.2)
UNACK flashes with horn · ACKED steady · RTNUN inverse flash (returned to normal, not yet acknowledged) · SHLVD / DSUPR / OOSRV never annunciate.

Alarm Summary
Location pane filters by unit or equipment (counts are active / unacknowledged) · ACK PAGE acts on the visible rows only · Cnt is the repeat count within 10 min · C marks a stored comment (COMMENT… button) · ALARM HELP opens the rationalisation pane · command KPI opens the alarm performance display · Help → Alarm and display philosophy (command PHILOSOPHY) explains the colours, states and the limit ladder; switching the colour philosophy (Station menu) needs SUPV and is journaled as a CONFIG change.

Plant orientation
Help → Plant orientation — what the units make… (command PROCESS, also OVERVIEW / PLANT) says what this plant makes, the route through it, each unit's hazards and how good the numbers are. PIP reads the same text. Our own prose about a plant that does not exist.

PIP cloud credential
Help → PIP cloud credential… (command CLOUDKEY, or the KEY button on the Ops Assistant) enters an API key for the cloud coach through a masked field. The key goes only to the local sidecar, is held in its memory for this session, and is never journaled, snapshotted, logged or shown to the model. FORGET KEY returns PIP to the local model. SUPV or above.

Instructor station
Command INSTR, Drills → Instructor Station…, or the SIM link in the status bar. Needs the instructor or manager password: run control (freeze / step / fast time), snapshots, initial conditions, backtrack, upsets (optionally hidden), plant variables, action journal with replay, live drill assessment.

Training and audit
Logon takes an operator name; it goes on every journal entry. Messages flagged CONFIRM count in the status bar (blinking MSG) until confirmed in the Message Summary. Critical changes (trip point, priority, out of service, PID tuning, disabling an asset's alarms, snapshot restore during a drill) need an electronic signature — password and reason. Every configuration change is a CONFIG event: command MOC opens the change log. Drills are scored against the 80 % mark ({{ dg.dbPassT }}); commands RECORD and COVERAGE open the training record and the operator task coverage matrix.

Operator Station Training Simulator
An independent, browser-based training aid reproducing the conventions of an Experion PKS Console/Flex Station: HMIWeb-style gray graphics, four alarm priorities (Journal/Low/High/Urgent), PID faceplates with MAN/AUTO/CAS, Point Detail with Experion parameter names (K, T1, T2 in minutes; SPHILM/OPHILM; SHEDHOLD…), alarm shelving, event journal, trends, and three live units: a continuous train with an exothermic CSTR, a semi-batch polymerization reactor with an SCM-driven sequence, and a fired-heater fixed-bed reactor. A rule-based Ops Assistant panel provides live diagnosis and coaching.

Not a Honeywell product; contains no Honeywell software, artwork, or manual text. High-priority yellow, summary columns, and key legends are representative defaults — sites configure these. Experion® is a trademark of Honeywell International Inc.
